# QA — sign-in and account dashboard

**Baseline:** develop @ `1111111`. Regenerate this plan when screens change.

## Roles

| Role | How to get one |
|---|---|
| Public | No account |
| User | Register through `/register` |
| Admin | Ask a developer for a seeded administrator (`🛠 needs dev`) |

## Test points

### 1. Sign-in

1. User opens `/login`, enters email and password → lands on `/dashboard`.
2. `NEG` Wrong password → the form shows the error; no redirect.
3. Account with 2FA → the OTP step appears; a correct code signs in.
4. `NEG` Five wrong OTP codes → locked; the lock message names the wait.

### 2. Dashboard

5. A `draft` account sees "Profile incomplete" and a Complete profile button.
6. Press Complete with fields empty → the missing fields are listed.
7. A `completed` account sees "Account ready" and no button.
8. The bell shows unread notifications; opening one marks it read.

### 3. Admin console

9. Admin opens `/admin` → a welcome card with links only to permitted modules.
10. `NEG` Admin without `users-view` types `/admin/users` → "no access" state,
    not an error page.
